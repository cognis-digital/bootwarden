# Polyglot implementations

Parallel implementations of **uefiscan** (Audit UEFI firmware dumps for missing Secure Boot keys, unsigned modules, S3 boot-script vulns, and known SMM threats.) across 9 languages, for reference and cross-language benchmarking.

- `python/` — python implementation
- `go/` — go implementation
- `rust/` — rust implementation
- `typescript/` — typescript implementation
- `c/` — c implementation
- `cpp/` — cpp implementation
- `java/` — java implementation
- `ruby/` — ruby implementation
- `csharp/` — csharp implementation
